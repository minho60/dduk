## 구현 상태

- **대시보드 KPI 및 위젯**: 종합 재고 수량, 재고 자산 가치, 안전재고 부족 건수, 이동 대기 및 최근 30일 출고량 실시간 연동 완료
- **창고 이동 워크플로우**: `PENDING -> APPROVED -> COMPLETED` 상태 보호 및 이중 재검증 완료
- **원가 계산**: 창고별 독립 이동평균단가 연산(BigDecimal scale 4, HALF_UP 반올림) 및 음수 재고 차단 완료
- **풍부한 시드 데이터**: 처음 구동했을 때 실제 ERP가 활발히 운영 중인 것처럼 느껴지도록 90일 치 거래 데이터 및 다양한 시계열 데이터 적재 완료

---

## 작성 및 준수 기준

- 실제 구현된 코드와 데이터베이스 스키마를 최우선으로 기록한다.
- 모든 API 명세, 파일 경로, 그리고 용어 정의(`current_stock`, `allocated_stock`, `average_cost` 등)는 프로젝트 공통 하네스 규칙을 철저히 준수한다.
- 향후 추가 고도화나 회계 도메인 자동 전표 연계 완료 시 본 문서 목록을 최신화한다.

# DDUK ERP AI 챗봇 테스트 가이드 (요약)

이 문서는 DDUK ERP AI 챗봇 환경을 간편하게 기동하고 테스트하는 핵심 절차만 정리한 요약 가이드입니다.

---

## 1. 사전 필수 확인
- 프로젝트 루트(`c:\kmh\dduk`)의 `.env` 파일에 데이터베이스 연결 정보 및 **`GEMINI_API_KEY`**가 올바르게 기입되어 있어야 합니다.

---

## 2. 챗봇 테스트 실행 절차

### Step 1. 통합 서버 기동
1. 프로젝트 루트 디렉토리에서 **`ai-all-start.bat`** 파일을 더블 클릭하여 실행합니다.
2. 스크립트가 백엔드(8080), AI 서버(5000), RPA 서버(5050), 프론트엔드(5500)를 자동으로 일괄 실행합니다.
3. 구동이 완료되면 브라우저에 `http://localhost:5500/index.html`이 자동으로 열립니다.

### Step 2. 로그인 및 테스트 메뉴 이동
1. 로그인 화면에서 다음 계정으로 로그인합니다.
   - **아이디**: `admin`
   - **비밀번호**: `admin123`
2. 왼쪽 사이드바 메뉴 하단의 **관리자 ➔ AI 챗봇 테스트**를 클릭하여 진입합니다.

### Step 3. 질문 및 응답 검증
1. 하단 질문창에 질의(예: *"인사 도메인의 핵심 기능은 무엇인가요?"*)를 입력하고 **전송** 버튼을 누릅니다.
2. 로딩 애니메이션이 나타난 후, AI로부터 한국어로 요약된 정상 답변이 화면에 출력되는지 확인합니다.
3. 우측 상단의 **대화 초기화** 버튼으로 대화 내역(메모리 history)을 리셋할 수 있습니다.

---

## 3. 이상 징후 발생 시 확인 (로그)
통신 에러 또는 무응답 발생 시 아래 로그 파일들을 열어 세부 에러를 확인합니다.
- **백엔드 로그**: `.local-run/[최신날짜-시각]/backend.out.log` 또는 `backend.err.log`
- **AI 서버 로그**: `.local-run/[최신날짜-시각]/ai-server.out.log` 또는 `ai-server.err.log`

# Inventory Docs

DDUK ERP 구매/재고 도메인 문서 영역이다.

## 문서 목록

| 문서 | 상태 | 설명 |
| --- | --- | --- |
| `INVENTORY_DASHBOARD.md` | 미작성 | 재고 대시보드, KPI, 발주/입출고 요약 |
| `STOCK_MOVEMENT.md` | 미작성 | 입고, 출고, 창고 간 이동, 재고 이력 |
| `WAREHOUSE_MANAGEMENT.md` | 미작성 | 창고, 위치, 창고별 재고 조회 |

## 작성 기준

- 실제 코드와 확정 문서를 우선한다.
- 초안이면 문서 안에 `상태: 미작성` 또는 `상태: 초안`을 명시한다.
- 구현 사실처럼 단정하지 않는다.
- 공통 규칙은 `docs/AI_HARNESS.md`, `docs/CONVENTION.md`, `docs/common/SYSTEM_ARCHITECTURE.md`를 따른다.

# Admin Backend Implementation Plan

## [x] Step 1. 인증 안정화
### 구현 기능
- `POST /api/v1/auth/login`
  - 로그인 ID, 비밀번호 검증
  - 비활성 계정 로그인 차단
  - JWT 발급
- `GET /api/v1/auth/me`
  - 현재 로그인 사용자 정보 반환
  - 토큰 기반 세션 복구 지원
- 로그인 이력 반영
  - 로그인 성공 시 `last_login_at` 저장

### 완료 기준
- 로그인 성공 후 관리자 프론트가 새로고침 시 사용자 정보를 복구할 수 있을 것
- 비활성 계정 로그인 차단이 유지될 것

## [x] Step 2. 관리자 계정 관리 운영화
### 구현 기능
- 관리자 계정 목록 조회
  - 키워드 검색: `loginId`, `name`
  - 역할 필터: `ADMIN`, `HR`, `INVENTORY`
  - 활성 여부 필터
  - 페이징, 정렬
- 관리자 계정 상세 조회
- 관리자 계정 생성
  - 중복 `loginId` 차단
  - 비밀번호 암호화
- 관리자 권한 변경
- 관리자 활성/비활성 변경

### 보호 규칙
- 자기 자신 비활성화 금지
- 마지막 활성 `ADMIN` 권한 제거 금지
- 마지막 활성 `ADMIN` 비활성화 금지

### 완료 기준
- 관리자 계정 목록이 검색과 필터 조건에 맞게 페이지 단위로 조회될 것
- 운영 사고를 막는 보호 규칙이 적용될 것

## [ ] Step 3. 관리자 대시보드 API
### 구현 기능
- `GET /api/v1/admin/dashboard`
- 계정 요약
  - 총 관리자 계정 수
  - 활성 계정 수
  - 최근 로그인 수
- 도메인 요약
  - 인사, 재고, 회계 핵심 카운트

### 완료 기준
- 관리자 첫 화면에 필요한 최소 통계가 한 API로 제공될 것
